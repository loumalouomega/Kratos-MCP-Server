The ProjectParameters.json in this directory makes the mesh and reference
paths self-contained, gives the case a descriptive problem name, and uses a
1e-6 check tolerance for the bundled nodal reference. It is generated from
the server's potential-flow template with the fixture's sub-model-part names;
the VTK output model part is fully qualified because Kratos requires a root
model-part path for that process.
